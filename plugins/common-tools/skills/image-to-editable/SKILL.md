---
name: image-to-editable
description: Create and inspect a local image-to-editable job using the common-tools CLI or MCP tools.
---

Use this skill only for files inside the approved workspace. Before using MCP, run `common-tools plugin enable --capability image-to-editable`; it is idempotent and enables this independently installed plugin without removing other installed capabilities. The local input must be a valid PNG, JPG, or JPEG no larger than 100 MiB, no wider or taller than 16,384 pixels, and no larger than 40,000,000 total pixels. This local capability requires an explicit workspace-contained slideclone config that declares its OCR, vision, rendering and quality providers; its `inputDir` must be the input file's directory and its `outputDir` must equal the requested output directory. It does not silently choose a provider. Prefer the `create_editable_job` MCP tool when it is available. Otherwise run `common-tools editable run --input <file> --out <directory> --config <slideclone.config.json>` and inspect the returned terminal Job. Do not request access to paths outside the workspace and do not claim conversion has completed until the Job has a terminal result and quality report.

For the optional remote team raw-image OCR profile, first create the exact Worker input with `common-tools team raw-image-archive --workspace <workspace> --input <png|jpg> --out <archive.tar.gz>`. Pass its returned `application/gzip` content type and content length to `create_team_upload_target`, upload that archive to the returned scoped URL, then call `create_team_job` with the returned object key and a fresh idempotency key. Never upload a raw image directly, choose an OCR executable/model/language through MCP arguments, or reuse an upload target for another capability. Team raw-image output is an original-image underlay plus editable OCR text overlay: until a cross-platform render-quality profile is configured, its quality report intentionally remains `passed=false`; report it as unverified rather than high-fidelity complete.
