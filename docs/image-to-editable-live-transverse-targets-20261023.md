# 共享线网的源绑定截面目标与真实主链核对

2026-10-23。补上此前曲线候选缺少的一个正式代码边界：截面目标现在由本次仍有效的私有源测量和原始像素产生，不再只能从旧诊断 JSON 读取。本轮没有把曲线候选写入输出；完整目标继续 active。

## 改动

新增 `routing/source-route-transverse-targets.js`，通过现有 measurement registry 的 `sharedSourceRouteTransverseTargets(fit, image, work)` 调用。注册表先验证 live fit、原始缓冲区身份、尺寸和完整内容摘要。复制或序列化 fit、复制像素、修改任意源字节及不安全控制均拒绝。新的读取逻辑不签发 source、paint、拓扑、擦除或输出凭证。

使用所有测量边建立两个源坐标索引，查询与当前截面相交的其他线臂和同边非局部部分；不会为每个样本重扫完整图。每个适合原生 polyline 的原采样都有一条分类记录。端口/接点区、邻近其他路径、边界不足、非不透明像素、侧翼不一致、低对比、多色混合、多重笔画和通道重心不一致均保留拒绝标记。

合格截面读取原始 25 像素横截面，不插值原图；两侧各两个像素构造局部线性背景，只有单一 paint 且通道重心一致时输出原始一阶矩目标。原 18 通道、42 对比和 .25px 通道重心约束保持。返回数据独立于源图和测量结果，修改它不能扩大源权限。

所有新增索引、像素读取、固定长度 pass 和数组准备均在原四百万几何预算内预留；超限抛出固定错误，不能发布已完成前缀。新模块已加入严格边界类型和实际运行包必需文件清单。主入口和默认编译器输出流程未修改。

## 真实 live fit 核对

使用同一真实截图、68 行冻结 OCR、已确认计划和 n10 host 授权，零次新模型调用。正常 raw rebuilder 重新产生私有 fit；仅在内存中于真实编译器返回前调用新接口和既有八步内核，磁盘编译器未改。原生产输出账本与新增候选账本分开记录，没有将两者称为一个完整新流水线。

- 12 条源边保持，其中 10 条有原生 polyline 测量，包含全部 **605** 个原样本。
- **3** 个原有端口桥段和 **64** 个可靠截面目标保持。
- 各目标的索引、法向偏移与冻结的独立 Python 观察一致；八步平滑逐样本与独立 Python 候选最大差异 **5.00744e-11px**。
- 新接口的截面读取消耗 **256763 checks**；八步内核 **357200 checks**。以原测量 **3116425** 为起点的独立候选账本为 **3730388**，原预算剩余 **269612**。
- 当前 auto 编译器测量后的输出与绑定开销是 **300737**。如果照搬这些开销，候选总计将为 **4031125**，已经超过原预算 **31125**，而且还没加入完整的新曲线拟合与拓扑工作。这只是基于实际分项的容量估算，不是完整曲线流水线的实测终态。

因此这轮不能启用曲线替换，也没有通过提高预算或删除困难截面让它通过。后续必须减少真实重复遍历/复制并完成有界曲线表示、连续几何、完整拓扑、输出快照和凭证组合，再用完整账本验收。
