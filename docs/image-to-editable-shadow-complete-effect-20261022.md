进一步只读观察正常冻结主链，取得原节点全部 5,946 个连通分量 cells 及隔离后的 4,066 个闭合环 cells。新阴影能解释拆出的 1,880 个 cells 中的 1,199 个；另外 681 个不能由该阴影单独解释，必须保留并区分边框、软边、关系等绘制归属。细线原完整 794-cell 余轴中，唯一越出原始路径半径的 `(450,510)` 同时处在原节点分量内，候选也能绘制它；这两项事实仍不足以直接给节点扩展私有 mask 或删去连线源像素。

正常冻结回放在只读观察下，全部 Deck 数据与上一成品一致，仅有两个随机图像目录名，经图像身份、完整元数据及字节摘要逐项校验。完整区域仍 **8/12**，11 条已接纳关系、12 条原观察、69 个文字对象、30 个图像及共享闭环均保留，两种语义与组件门禁继续失败。首次观察器误把正常被拒绝的小组件当作必须成功的环，导致一次诊断失败；失败及修正后完整回放均保留，没有为观察器改变生产判断。
