# 推测直线端点源证据修复

本轮修复视觉原子直线的生成错误：旧过滤器按整条线的平均误差决定是否保留，中段有墨迹时，可能仍在实际端点只有背景的位置画线。新增独立端点检查只否决被源图反证的推测线，不授予对象归属、分组或残差擦除权限。

`source-line-terminal-contradiction.js` 检查未绑定、无变换、纯色平端水平/垂直线的两个原始端点。每端使用一源像素宽的完整横截面，要求两侧背景独立一致，且横截面所有核心样本都更接近背景并超过既有 18 通道颜色界限。非均匀背景、不可用透明证据和不支持的几何不产生新增否决；所有读取计入原共享 4M 像素预算。整原子在输出和擦除前被拒绝，对应源图回退保留。

13 项新回归覆盖双方向水平/垂直线、独立比例、真实卡片边缘裁片、源回退、完整端点、非均匀与透明证据、语义绑定/变换/箭头例外、预算、非法输入与访问器、极端几何及颜色容差。精确旧过滤器运行同一新回归为 8 通过、5 失败；修复后与既有视觉原子回归合计 114/114，通过统一 unit 发现，无测试豁免。早期诊断与测试夹具错误记录均保留。
