# 固定视觉候选分类实验（2026-10-30）

## 目标和交付范围

将“定位”和“语义分类”分开：像素分析先生成固定候选框，模型只返回稳定候选 ID、
类别、置信度和完整性假设，禁止模型在该路径生成坐标、归属、连接关系或擦除权限。
这是实验模块，尚未接入生产默认场景规划器。

新增模块：

- `packages/slideclone-core/scene-plan/source-scene-visual-candidates.js`：
  复用现有颜色连通域检测，生成来源绑定候选与遗漏计数。
- `packages/slideclone-core/scene-plan/source-scene-candidate-classification.js`：
  生成严格分类提示并验证完整 ID 绑定；拒绝多余坐标、身份替换、重复和缺失结果。
- `packages/slideclone-core/scene-plan/source-scene-candidate-coverage.js`：
  在固定 IoU≥0.5 下进行一对一最大匹配，度量人工标注子集上的候选召回率。

未增加外部依赖，未修改既有生产门槛，未部署或提交工作区其他修改。

## 方法与边界

检测器使用固定深色墨迹阈值与 4px 原始组件邻近关系；先产生位置，不假定类别。
有几何重叠的组件不会因包围框的空白区域而被合并，避免面板边框吞掉内部内容。
候选不屏蔽 OCR 框，避免把 OCR 误识别的图标提前抹掉。

单张扫描限制 4M 像素，原始组件最多 2048，候选最多 256，单候选包围框最多 262144 像素。
超大组明确计数，超出组件或候选容量时明确失败，不静默截断。
待分类样本按面积从大到小排序取前 32 个，其余候选明确记录为未审核。
这些是实验资源约束，不替代现有生产输入能力或质量门槛。

完整性、类别和模型置信度均为提案。任何输出都不授予原生端口、源像素、背景例外、擦除或最终质量通过权限。
墨迹阈值对浅色、低对比度、纹理和密集相接对象存在明显局限，不能据此宣称通用图标检测已完成。

## 在线分类与失败证据

用户此前已批准复用现有 HTTPS-Proxy 配置与凭据。
第一轮流式分类返回 `SCENE_PROVIDER_STREAM_FAILED`。
保持相同来源、候选、标注和提示，改用非流式后返回 `SCENE_HTTP_FAILED`。
为区分转发与上游，直接调用同一代理的相同完整分类请求，获得 HTTP 502。

对照诊断中：主机纯文本请求、容器纯文本请求，以及使用相同图集但要求空 JSON 的小输出图像请求均返回 HTTP 200。
这排除了“服务完全不可达”或“图像输入完全不可用”的推断；尚不能确定完整请求失败的上游根因。
未轮换凭据、修改代理配置、切换模型或增加请求/质量预算。
未记录凭据、请求头、签名 URL 或错误响应正文。
没有获得通过严格分类协议的实际模型响应，因此分类效果仍未验证。
