## 已修复

### 箭头重复接点导致伪分叉

上层真实箭头附近的两个私有接点被当成两个终端，阻断完整箭头测量，并留下 5/6 像素的小分支。新模块 `routing/source-shared-head-contacts.js` 仅在完整源箭头的渐缩区覆盖同一节点的所有候选接点时归并。

归并保留一个原先已私有验证的接点，不虚构中心、不增加附件距离、不修改源 mask。长箭颈不属于接点归并证据；候选 tip 必须是实际箭头极端。不同箭头、不同节点、独立接点、原始分支和超限工作仍保留拒绝。归并后重新执行完整箭头、树、方向及覆盖证明。

### 私有节点轮廓被误当成间隙背景

下层目标的私有轮廓跨越几何框边缘，某行七个中心像素均已由该轮廓拥有，但旧逻辑仍先比较四个背景 flank 而拒绝。现在该整行不参与外部背景证明；仍要求至少一行独立外部空白证据，原有 alpha、42 对比、90%/18 色差、障碍及四百万工作预算保持不变。

没有按颜色跳过异常像素；伪造 token、复制源缓冲、局部拥有、只有拥有行、空白走廊插入墨迹和预算耗尽均有反例。

### 独立保留源空间渐变证明

`routing/source-route-spatial-paint.js` 对全部原始核心样本独立拟合 x/y 轴颜色，采用相同 90%/18 门槛并计入既有工作账本。简化、全局坐标平移和冻结 fit 保留该模型；编译器不再把弧长插值颜色当成源空间证据。

长 Z 形、x/y 转置、正反方向回归覆盖旧插值拟合失败而实际源空间模型通过的情况。真正非空间渐变继续分段；未提高颜色误差、支持率或停止数量上限。

### Worker 显式区分两类编辑能力

新增配置：`COMMON_TOOLS_IMAGE_CONNECTOR_CORNER_MODE=auto|rounded-freeform|reroutable-elbow`。两个 OCR Compose overlay 均转发此变量；解析在文件和 OCR profile 访问前执行。默认继续为 `reroutable-elbow`，保持现有生产自动重路由要求。

显式选择 `auto` 或 `rounded-freeform` 后，Worker 采用原生路径编辑策略。`worker-relationship-policy.js` 用每作业异步上下文隔离配置，候选、阴影候选、文本/面板/字重细化、最终审计共享同一策略；Deck 中的模式标签不授权修改门禁。

原生路径策略检查真实开放 command stream、无填充有效描边、唯一目标、端点几何、合法锚点和无冲突变换。单线圆角编译现在保留原有端点元数据。填充轮廓、闭合、多子路径、伪模式标签、缺失/重复目标和脱离端点仍拒绝。

报告明确给出 `nodeMoveRerouting: false`；交付指标保留路径数量、非重路由数量及是否要求节点重路由。默认核心审计仍要求节点重路由，未把 freeform 称为自动重路由连接器。配置尚未在共享运行时启用。

### 防止静默删除源图闭环

后续回归发现旧 `breakSkeletonCycles` 会把真实闭环的最长一段删除，然后把剩余图当成树。小闭环的缺失部分还可能落在接点覆盖半径内，因此不能仅依赖下游像素覆盖发现这种拓扑损失。已移除删环处理：完整连通图一旦不满足树契约，返回明确的 `shared-shaft-cycle`，不授予源路由证明。

保留旧 `sourceSharedShaftTree` 的 tree/null 调用契约，新增内部诊断入口 `inspectSourceSharedShaftTree` 并贯通生产源测量。小/大闭环、不同终端枚举顺序、真实源测量、输入不变、空图/断图和预算耗尽均有回归。该修复阻止错误接受，**没有实现闭环的原生编译**。
