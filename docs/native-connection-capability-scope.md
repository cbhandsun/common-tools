# 原生连线能力与验证边界

## 输入与输出约定

本能力处理已经确定节点、方向和有序关系路径的线网。图片识别、端点身份判断和歧义确认是上游步骤；连接器编译成功不能替代它们。未知或有冲突的关系不得根据距离猜测为成功。

在可表示的路径上，每条业务关系输出一个完整原生连接器，并绑定两端实际对象及端口。共享物理边仍可由不同业务关系经过；不把一条业务关系拆成数条直线来满足完整计数。未被业务路径使用的独立辅助臂单独记录，不能冒充业务关系。

默认 `reroutable-elbow` 选择原生直角连接器，优先保持关系和双端绑定。显式 `auto` / `rounded-freeform` 可选择原生开放圆角路径；它们的结构可编辑性与节点移动后的行为分别报告。颜色和圆角外观不授予关系身份、源像素或自动跟随能力。

## 共享线网编辑

生产 IR 编辑入口 `common-tools ppt apply-ir-edit` 支持 `reflow-native-network`。编译页面保存 `source.nativeNetworkEditModels`，编辑通过当前节点位置和保存的网络模型整网求解，验证后原子应用。后续操作失败时，不发布前面已完成的局部重排。

在启用 `ppt-create` 能力的现有工作区，补丁使用当前 IR 的 revision，并在节点的 `set-box` 操作之后加入以下操作；`networkId` 取自该页 `source.nativeNetworkEditModels[].id`。它是保存模型的标识，不是固定样本 ID。输入必须是保存了该模型的 IR；旧 PPTX 不会因直接导入而自动获得完整线网模型。

```json
{"type":"reflow-native-network","pageIndex":0,"networkId":"saved-network-id","approximation":"semantic-native"}
```

```powershell
common-tools ppt apply-ir-edit --input deck.json --patch edit.patch.json --out deck.edited.json
common-tools ppt export-ir --input deck.edited.json --out exported
```

第一步更新 IR 并返回 `networkReflows` 报告；第二步使用现有导出入口写出 PPTX 等产物。界面或调用方应明确提供“整网重排”操作；本接口不监听 PowerPoint 的独立拖动事件。

支持的正交几何仍须满足连接器表示、端口、路径次序、相交、拓扑和累计工作预算检查。旋转节点、不一致锚点、未知成员、交叉编辑或不能表示的路径会明确失败；不能据此承诺任意拓扑和任意节点拖动都可自动重排。

全部终端发生同一平移时，完整保留骨架及未绑定端点的内部轨道共同平移，再经过上述原检查。合成回归覆盖独立直线、折线、树和闭环的 80 组缩放、镜像与平移组合，包含小数、负向和零位移；终端合法但辅助轨道移出支持坐标域时仍拒绝。非一致节点编辑继续使用原轴约束求解。

用户当前接受的共享闭环维护方式是工具显式整网重排。PowerPoint 独立拖动后自动保持闭环尚未验证通过；`automaticOfficeFollowingVerified=false` 保留。连续连接器几何的闭环检查也不能替代带虚线、透明度等实际绘制效果的完整拓扑证明。

## 本轮通用修复

| 模块 | 可复用行为 | 保留的拒绝边界 |
| --- | --- | --- |
| 区域端点引用 | 区域引用已有完整容器，避免重复申领物理成员 | 必须是同区域唯一 owner、完整成员集合和当前实际输出 |
| 历史路径重绑定 | 同源几何未变时，允许底层边编号改变 | 源摘要、尺寸、接点及每个有序顶点精确相同，双向唯一匹配；不跨图迁移确认 |
| owner 复核调度 | 分开观察完整区域，减少矩形图集空白造成的预算浪费 | 每组仍需双视图，累计原像素、成员及调用预算；失败后不返回部分计划 |
| 图标隔离与像素观察框 | 默认触边窗口有界扩展，观察框向外取整为完整源像素 | 显式窗口、文字归属、源证据及原预算检查保留 |
| 线网编译与重排 | 整条连接器、原端点、路径次序和共享闭环共同校验 | 不支持的几何明确拒绝，不借助拆线或修改计数制造通过 |

人工确认的路径、外框拟合和背景像素近似仍绑定各自源图，不是其他图片的自动授权或识别模板。

## 验证覆盖

合成回归覆盖直线、闭环、有序反向路径、平移、镜像、缩放、额外连通分量、丢环和新增环；页面事务回归覆盖原图提取的树形和闭环网络、移动缩放、重复重排、过期 revision、交换或缺失端点、预算耗尽、恶意输入及失败回滚。测试进入统一 CI。合成拓扑回归不是多图真实 Office 验收。

当前真实 Office 证据仅来自一张源图的副本：生产工具重排后另存、关闭、重开，11/11 完整原生业务连接器及原双端绑定保持，路径最大误差 0pt，下层连续几何采样为一个连通分量、一个闭环。证据位于 `.codex-temp/semantic-final-gates-20261028-v1/current-production-network-v5/office-saved-audit.json`。

独立新识别 v19 的全部 11 条关系均已编译，但区域程序、清点一致性及一项文字源证据未通过，整页自动转换仍失败。没有多张真实图片端到端验收或跨图成功率基准，不能把当前结果表述为“任意截图一步成功”。完整 CI 的终态以 `image-to-editable-closeout-status-20261028.md` 及其关联证据为准。
