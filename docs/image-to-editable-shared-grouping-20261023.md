## 生产实现

`source-shared-route-output-groups.js` 使用编译器私有 WeakMap，绑定一次完整测量产生的全部成员、绘制快照及源凭证。最终分组保留检查完整成员、唯一性、顺序、外部端口、绘制顺序和原几何预算。公开分组 ID、复制对象或序列化记录不能制造凭证。

`source-shared-route-compiler.js` 为同一网络生成共同 `nativeComponentGroupId`，控制点与连接器共同入组。`source-scene-finalize.js` 将其保留凭证并入现有清理流程。外部业务节点不加入网络组。

首次实现重复序列化快照，实际回放耗尽原有 400 万几何预算。修复后复用 `source-shared-route-output-paint.js` 已生成的快照 Map 副本，没有扩大预算。凭证只保留分组，不增加绘制、源归属或擦除权限。
