## 为什么后续记录看起来回退

后续在 `auto` 模式试验新的圆角自由曲线。自由曲线作为原生矢量可以编辑路径，但不能继承 `<p:cxnSp>` 连接器已经通过的节点拖动跟随结果。圆角拟合、源像素检查或单元测试通过，都不能替代这项产品能力。

最新圆角候选 [v6](../.codex-temp/shared-cubic-chain-20261023-v6/capture-result.json) 和随后 [原生模式回放](../.codex-temp/shared-native-regression-20261023-v1/capture-result.json) 均为 `exitCode: 1`。两个回放都在 `approved-frame-application.js:68` 的图片摘要绑定处停止，没有生成通过验收的新正式 PPT。拒绝发生于已批准外框资产的绑定检查，不能描述为原生连接器退回截图、关系丢失或新版本已经交付。

此前把候选失败、完整区域未完成和已通过的原生连线混在一起描述，导致有效基线不清楚。后续必须同时标明产物路径、连接器能力和验收范围。
