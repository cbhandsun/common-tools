# 图片转可编辑 PPT：箭头截面零面积交集修复

修复了原始像素截面中的零面积交集错误。冻结输入的实际 raw 重建器回放仍为 **4/11** 条关系；修复前后整个 deck 严格相等，组件门禁、严格语义门禁及原生路径语义门禁仍失败。本轮没有通过调整阈值接纳跨区线，也没有完成整页验收。

## 修复及回归

[source-filled-arrow-slices.js](../packages/slideclone-core/routing/source-filled-arrow-slices.js) 将原始单位像素与单位宽度截面相交。旧实现只检查横向区间长度，沿轴方向仅共享一条边的交集也可能产生非零横向区间。因此，邻行像素会扩大截面，并可能填平本截面中的真实缺口。

现在先要求沿轴方向具有正长度重叠，再计算原始多边形交集。真正具有正面积的斜向角部交集仍保留。没有改变源像素、截面尺度、箭头尺寸、颜色误差、支持率、头部容量或几何工作账本。

最小回归的两个原始像素中间有一个单位缺口，邻截面另有一个像素。旧结果将本截面的 `gaps` 算作 0、相邻截面宽度算作 3；修复后分别为 1 和 1，并且不再产生两端两个没有面积的截面。

新增 [source-filled-arrow-slices.test.js](../test/source-filled-arrow-slices.test.js) 覆盖两轴、真实缺口、斜向角部、源数据不变、空观察及耗尽工作预算。通过正式 unit 发现器进入统一 CI。修改前四项测试中两项失败，修改后与头部、复合路由、实心箭头和共享接触点测试合计 **28/28** 通过，零跳过。
