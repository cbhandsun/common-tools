# PPT Quality Standards

Use the same audit baseline as `$ppt-quality-assessor`.

## Hard Gates to Fix First

- Missing or duplicate slide titles
- Illegible contrast
- Body text below practical readability thresholds
- Color-only meaning
- Broken reading order
- Missing alt text when accessibility matters
- Unreadable charts, legends, or labels

## Repair Priorities

1. Make the slide readable.
2. Make the main point obvious.
3. Remove non-essential noise.
4. Restore consistency with surrounding slides.

## Practical Thresholds

- Body text: usually at least 18 pt
- Titles: usually at least 24 pt
- Live-talk decks: often aim larger; 30 pt is a good stretch target, not a universal law
- Prefer sans-serif type
- Prefer left-aligned paragraph text

## Communication Rules

- One dominant idea per slide is the default for talk-driven decks.
- A slide should pass a fast 3-second comprehension test.
- Whitespace is functional, not wasted.
- Visual hierarchy must show what matters first.
- Consistency should help the audience predict structure.
