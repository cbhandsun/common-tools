# PPT Quality Standards

Use this file as the audit rubric for "what makes a strong PPT".

## Source Base

This rubric is distilled from:
- Microsoft Support accessibility guidance for PowerPoint:
  https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities
- Microsoft 365 10-20-30 article:
  https://www.microsoft.com/en-us/microsoft-365-life-hacks/presentations/10-20-30-rule-of-powerpoint
- Garr Reynolds presentation design tips:
  https://www.garrreynolds.com/design-tips

## 1. Hard Gates

Fail a slide on hard gates when any of these materially break comprehension or accessibility:

- Every slide needs a unique title.
- Text/background contrast must be strong enough to read easily.
- Do not rely on color alone to carry meaning.
- Body text should normally be at least 18 pt; titles should normally be at least 24 pt.
- Prefer sans-serif fonts.
- Dense paragraph text should usually be left-aligned, not justified.
- Images and meaningful visuals should have alt text when the deliverable must remain accessible.
- Reading order should match intended reading flow.
- Hyperlinks should use meaningful text, not raw "click here".

## 2. Core Quality Dimensions

### Narrative and Message Focus

Ask:
- Is the deck clear about what it wants the audience to know, decide, or do?
- Does each slide support that arc?
- Does each slide mostly carry one message instead of several competing ones?

Inference from the sources:
- "One idea per slide" is a strong default for live presentations, but document-style decks can hold more density if hierarchy stays obvious.

### Glance-Test Clarity

Use Duarte's 3-second test:
- Look at the slide briefly.
- If the main point is not obvious, the slide is overloaded or weakly prioritized.

Signals of failure:
- No dominant takeaway
- Too many equal-weight objects
- Long paragraphs before focal insight
- Charts or diagrams with no obvious entry point

### Visual Hierarchy and Layout

Use Duarte's five critique elements:
- Contrast
- Whitespace
- Hierarchy
- Unity
- Flow

Check:
- Is there one dominant focal point?
- Are related elements grouped?
- Is spacing intentional?
- Does the eye know where to start and where to go next?

### Typography and Readability

Check:
- Can the last row read it?
- Are line breaks intentional?
- Is there too much text per slide?
- Are titles short enough to stay visually dominant?

Use Microsoft 30 pt guidance as a stretch target for projected, talk-driven decks.
Do not force 30 pt on dense leave-behind decks if it breaks the deck's function.

### Consistency and Unity

Check:
- Consistent title placement
- Stable grid and margins
- Repeated styles for repeated content
- Controlled color palette
- Consistent icon/image treatment

Weak unity usually shows up as:
- Random font changes
- Inconsistent caption styles
- Cards and diagrams using unrelated spacing rules
- Arbitrary decorative shapes

### Data Display Quality

Check:
- Is the chart type appropriate for the message?
- Is the main comparison obvious?
- Are labels, units, and time windows clear?
- Is non-essential chart ink reduced?
- Is the audience told what matters, not just shown raw data?

For tables:
- Keep only needed columns
- Use emphasis sparingly
- Reduce border noise
- Make scan path obvious

### Accessibility and Inclusive Design

Check:
- Unique titles
- Reading order
- Contrast
- Color-independence
- Alt text where needed
- Legible font sizes
- Meaningful link text

## 3. Signal-to-Noise Rules

Borrow Garr Reynolds' principle:
- Remove anything that does not help the message.

Common noise:
- Decorative lines with no meaning
- Repeated labels that the layout already implies
- Logos and footers that dominate content
- Overspecified tables
- Tiny legends when direct labels would work better

## 4. Scoring Rubric

Score each dimension `0-3`.

- `3`: strong, clear, presentation-ready
- `2`: workable but needs improvement
- `1`: weak, repeatedly obstructs comprehension
- `0`: broken or missing

Suggested interpretation:
- `18-21`: strong deck
- `14-17`: usable but should be repaired
- `9-13`: weak deck with multiple structural problems
- `0-8`: major rework needed

## 5. Findings Format

Use this format:

`[Priority] Slide X - Problem - Why it hurts - Smallest effective fix`

Example:

`[P1] Slide 6 - Three equal-weight charts compete for attention - audience cannot tell the main takeaway quickly - enlarge the lead chart, demote the other two to supporting size, and add one takeaway title.`
